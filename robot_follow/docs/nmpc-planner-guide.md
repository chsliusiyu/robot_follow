# NMPC 避障规划器 — 算法说明与参数调优

## 1. 整体架构

```
UWB串口 ──→ processtalker() ──→ state_.setTarget(x, y)
                                      │
LiDAR ──→ processScan()                │
              │                        │
              ├─ 障碍物过滤 ───────────┤
              │   · 去inf/nan          │
              │   · 去机器人框架        │
              │   · 去目标遮罩          │
              │                        │
              ├─ state_.getTarget() ◄──┘
              ├─ state_.getVelocity()   (当前速度)
              │
              ├─ [UWB超时?] → vx=0, vy=0, wz=0.5 搜索旋转
              │
              ├─ NMPC.solve(障碍, 目标, 当前速度) → 最优(vx,vy,wz)
              │
              ├─ [到达目标?] → vx=0, vy=0, wz=P控制朝向
              │
              └─ publishVelocity()
```

## 2. NMPC 算法详解

### 2.1 系统模型

状态 z = [x, y, θ]^T（机器人坐标系中的相对位姿），控制 u = [vx, vy, wz]^T：

```
x_{k+1} = x_k + (vx_k·cos(θ_k) - vy_k·sin(θ_k)) · dt
y_{k+1} = y_k + (vx_k·sin(θ_k) + vy_k·cos(θ_k)) · dt
θ_{k+1} = θ_k + wz_k · dt
```

- 预测步数 N = 15，步长 dt = 0.1s → 1.5s 前视
- 优化方法：梯度下降 + 伴随法反向传播，无外部求解器

### 2.2 代价函数

**阶段代价**（每步累加，k = 0..N-1）：

```
L_k = W_OBS × Σ exp(-d_i² / σ²)           // 障碍排斥（指数场）
    + W_SMOOTH × (Δvx² + Δvy² + Δwz²)     // 控制平滑（抑制突变）
    + W_CTRL × (vx² + vy² + wz²)           // 控制代价（偏好低速）
```

**终端代价**（第 N 步）：

```
φ_N = W_TRACK × (dist_end - FOLLOW_DIST)²  // 跟踪误差
    + W_HEAD × angle_end²                  // 朝向误差
```

- dist_end = 轨迹终点到目标的距离
- angle_end = 轨迹终点处目标在机器人坐标系中的偏角

**硬否决**：轨迹上任何点到障碍距离 < EMERGENCY_DIST → 代价 = +∞（不可行）

### 2.3 优化流程

```
1. Warm start: 上一帧最优控制序列 shift 一位后作为初值
2. for iter = 1..MAX_ITER(30):
   a. 前向仿真 → 计算代价
   b. 伴随法反向传播 → 计算梯度
   c. U = U - step × gradient
   d. 投影到速度/加速度约束
   e. 梯度范数 < 收敛容差 → 退出
   f. 步长衰减 step *= 0.98
3. 输出 U[0]，施加距离自适应速度 clamp
```

### 2.4 约束投影

**速度盒约束**（projectBox）：
```
vx ∈ [-0.30, 0.30],  vy ∈ [-0.30, 0.30],  wz ∈ [-1.0, 1.0]
```

**加速度约束**（projectAccel，递归）：
```
u₀ ∈ [current - acc×dt, current + acc×dt]
u_k ∈ [u_{k-1} - acc×dt, u_{k-1} + acc×dt]
```

### 2.5 距离自适应速度

输出 vx 按目标距离衰减（nmpc_planner.hpp:225-230）：
```
dist_factor = clamp((target_dist - 0.6) / (3.0 - 0.6) × 0.8 + 0.2, 0.1, 1.0)
vx_out = clamp(vx_optimal, -MAX_VX × dist_factor, MAX_VX × dist_factor)
```

| 目标距离 | dist_factor | 最大前向速度 |
|----------|:---:|:---:|
| 0.6m | 0.10 | 0.03 m/s |
| 1.0m | 0.23 | 0.07 m/s |
| 1.5m | 0.40 | 0.12 m/s |
| 2.0m | 0.57 | 0.17 m/s |
| 3.0m | 1.00 | 0.30 m/s |

### 2.6 到达目标停驻 + 朝向对齐

触发条件：`|目标距离 - 0.6| < 0.1`（目标在 0.5~0.7m 范围内）

```
vx = 0,  vy = 0
wz = clamp(atan2(target_y, target_x) × 0.6, -0.4, 0.4)
```

P 控制器增益 0.6，限幅 ±0.4 rad/s。目标走远后自动恢复 NMPC 跟随。

### 2.7 UWB 信号丢失搜索

超时 2 秒未收到 UWB 数据：

```
vx = 0,  vy = 0,  wz = 0.5    // 原地缓慢旋转
清除 NMPC warm start           // 信号恢复后不继承旧序列
```

信号恢复后自动退出搜索模式。

## 3. 参数一览

### 3.1 速度约束（common_types.hpp）

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `NMPC_MAX_VX` | 0.30 | 前向最大速度 (m/s) |
| `NMPC_MIN_VX` | -0.3 | 后退最大速度 (m/s) |
| `NMPC_MAX_VY` | 0.3 | 横向最大速度 (m/s) |
| `NMPC_MIN_VY` | -0.3 | 反向横向最大速度 (m/s) |
| `NMPC_MAX_WZ` | 1.0 | 旋转最大速度 (rad/s) |
| `NMPC_MIN_WZ` | -1.0 | 反向旋转最大速度 (rad/s) |

### 3.2 加速度约束（common_types.hpp）

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `NMPC_ACC_VX` | 0.5 | 前向加速度 (m/s²) |
| `NMPC_ACC_VY` | 0.5 | 横向加速度 (m/s²) |
| `NMPC_ACC_WZ` | 2.0 | 角加速度 (rad/s²) |

### 3.3 代价权重（common_types.hpp）

| 参数 | 默认值 | 代价形式 | 说明 |
|------|--------|----------|------|
| `NMPC_W_TRACK` | 5.0 | `5.0 × (dist-0.6)²` | 终端跟踪误差 |
| `NMPC_W_HEAD` | 1.5 | `1.5 × angle²` | 终端朝向误差 |
| `NMPC_W_OBS` | 10.0 | `10.0 × Σexp(-d²/σ²)` | 障碍排斥 |
| `NMPC_W_SMOOTH` | 2.0 | `2.0 × ΣΔu²` | 控制平滑 |
| `NMPC_W_CTRL` | 0.1 | `0.1 × Σu²` | 控制代价（偏好低速） |

### 3.4 障碍物参数（common_types.hpp）

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `NMPC_OBS_SIGMA` | 0.15 | 指数衰减宽度 (m)。值越大排斥范围越大 |
| `NMPC_OBS_CUTOFF` | 0.5 | 障碍物影响截止距离 (m) |
| `NMPC_EMERGENCY_DIST` | 0.25 | 硬否决距离 (m)，到障碍小于此值直接否决 |
| `TARGET_MASK_RADIUS` | 0.45 | UWB 目标周围排除障碍的半径 (m) |

### 3.5 优化参数（common_types.hpp）

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `NMPC_HORIZON` | 15 | 预测步数，15×0.1=1.5s 前视 |
| `NMPC_DT` | 0.1 | 仿真步长 (s) |
| `NMPC_MAX_ITER` | 30 | 最大梯度下降迭代次数 |
| `NMPC_CONVERGE_TOL` | 1e-3 | 梯度范数收敛容差 |
| `NMPC_INIT_STEP` | 0.02 | 初始梯度步长 |
| `NMPC_MIN_STEP` | 1e-4 | 最小梯度步长（步长衰减下限） |

### 3.6 跟随/搜索参数（common_types.hpp）

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `FOLLOW_DIST` | 0.6 | 理想跟随距离 (m) |
| `UWB_TIMEOUT_S` | 2.0 | UWB 丢失后多久触发搜索 (秒) |
| `UWB_SEARCH_WZ` | 0.5 | 搜索时原地旋转速度 (rad/s) |

### 3.7 硬编码参数（lidar_tracker.hpp）

| 位置 | 值 | 说明 |
|------|------|------|
| 停驻距离阈值 | `|dist - 0.6| < 0.1` | 到达目标判断（0.5~0.7m） |
| P 朝向增益 | `atan2(y,x) × 0.6` | 角度误差转 wz 的比例 |
| P 朝向限幅 | `±0.4 rad/s` | 朝向对齐最大转速 |
| 距离因子下限 | `clamp(..., 0.1, 1.0)` | 最近时速度降至最高速的 10% |

## 4. 常见场景调优

### 场景1：速度太快，想再慢点

```
减小 NMPC_MAX_VX (0.30 → 0.20)
减小 NMPC_ACC_VX (0.5 → 0.3)
提高距离因子下限 (0.1 → 0.05，在 nmpc_planner.hpp:228)
```

### 场景2：机器狗不完全面朝目标

```
增大 W_HEAD (1.5 → 2.0)
增大停驻时 P 增益 (0.6 → 1.0，lidar_tracker.hpp:231)
```

### 场景3：机器狗仍然绕人转圈

```
减小 W_HEAD (1.5 → 1.0) — 降低朝向代价，减少 wz 优化
减小 NMPC_MAX_WZ (1.0 → 0.5) — 限制旋转速度
考虑禁用 warm start（删除 nmpc_planner.hpp:53-54 的 shift 逻辑）
```

### 场景4：躲避障碍物不够灵敏

```
增大 W_OBS (10.0 → 15.0)
增大 OBS_SIGMA (0.15 → 0.20) — 扩大排斥范围
减小 EMERGENCY_DIST (0.25 → 0.30) — 更早触发否决（更保守）
```

### 场景5：避障太激进，绕大圈

```
减小 W_OBS (10.0 → 6.0)
减小 OBS_SIGMA (0.15 → 0.10)
增大 W_TRACK (5.0 → 8.0) — 更重视缩短距离
```

### 场景6：UWB 目标附近真实障碍物被误排除

```
减小 TARGET_MASK_RADIUS (0.45 → 0.25)
```

### 场景7：信号丢失后转太慢/太快

```
增大/减小 UWB_SEARCH_WZ (0.5 → 0.3 或 0.8)
减小 UWB_TIMEOUT_S (2.0 → 1.0) — 更快触发搜索
```

### 场景8：动作太突兀，加减速太猛

```
减小 ACC_VX, ACC_VY, ACC_WZ
增大 W_SMOOTH (2.0 → 3.0) — 更强平滑约束
```

## 5. 已知问题

| 问题 | 原因 | 改进方向 |
|------|------|---------|
| 走着走着转圈 | Warm start 继承上帧 wz，逐帧累积旋转 | 衰减 warm start 的 wz 或不启用 warm start |
| UWB 丢失追假位置 | target 冻结在最后有效值 | 缩短超时时间，或加卡尔曼预测 |
| 距离近时不会后退 | W_CTRL 抑制大速度但无方向偏好 | 双向速度评分 |
| 梯度下降可能局部最优 | 非凸优化，初始点影响大 | 多初始点或随机扰动 |

## 6. 与 DWA 对比

| 维度 | DWA | NMPC |
|------|-----|------|
| 搜索方式 | 速度空间采样 + 评分 | 控制序列梯度优化 |
| 前视能力 | 1.5s 开环预测 | 1.5s 闭环优化 |
| 轨迹质量 | 采样最优（离散） | 梯度最优（连续，局部） |
| 平滑性 | 加速度约束 | 显式平滑代价 + 加速度约束 |
| 障碍处理 | 轨迹碰撞检测 + 密度罚分 | 光滑指数惩罚场 |
| 计算量 | O(525 × 15 × N_obs) | O(30 × 15 × N_obs) |
| 参数数量 | ~20 | ~25 |
| 外部依赖 | 无 | 无 |
